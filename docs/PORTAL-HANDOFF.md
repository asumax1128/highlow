### 一覧用の紹介文

左右の数式を比べて、大きい方をタップ！ 考える時間30秒で、ひらめきと計算力に挑む数学アーケード。3つの難易度と、デイリー・週間・歴代ランキングに対応。

### 詳細ページ用の概要

左右に並ぶ2つの数式。大きいのはどっち？ HIGH×LOWは、式の値をすばやく見比べて答えるソロ数学ゲームです。EASYは小学校レベルの四則演算で左右の2択、NORMALでは同じ値を選ぶEQUALが加わり、HARDでは分数・平方根・三角関数などの比較に挑戦できます。考える時間は30秒。連続正解で得点を伸ばし、難易度別のデイリー・週間・歴代ランキングで自己ベストを目指しましょう。

### 特徴

1. タップで大きい方を選ぶ直感的な操作。PCの矢印キーにも対応。
2. EASY・NORMAL・HARDの3難易度。HARDの数式は分数・平方根などを読みやすく表示。
3. 考える時間30秒。連続正解でコンボをつなぎ、ハイスコアに挑戦。
4. 難易度別のデイリー・週間・歴代ランキング。上位100名と自分の順位を確認可能。

### 遊び方

1. 難易度を選択してPLAYを押します。
2. 左が大きければLEFT、右が大きければRIGHT。同じ値ならEQUAL。EASYはEQUALなしの2択です。
3. 考える時間は30秒。正誤表示の0.3秒間は時計が停止します。
4. ランキングへの掲載はRANKINGでニックネームを登録し、オンラインで試合を完走すると自動反映されます。
5. PC操作は←＝LEFT、→＝RIGHT、↓＝EQUAL。別タブ・別アプリへの移動は試合中断となり、その試合はランキングへ登録されません。

## ポータルへの追記方法

確認したポータルは `data/games.json` から一覧と詳細ページを生成し、`public/assets/` に素材を置く構成です。現在の最新コードを確認したうえで、次の順で作業してください。

1. 既存作品・既存URL・現在の構成を確認する。
2. 同梱のロゴと3枚のスクリーンショットを上記のコピー先へ追加する。
3. `portal-handoff/game-entry.json` のオブジェクトを `data/games.json` の配列へ追記する。既存配列全体を置き換えない。
4. `id: "high-low"` が未使用であることを確認する。
5. `npm run build` を実行し、一覧・詳細ページ・PLAYリンク・ロゴ・ギャラリーを確認する。
6. スマートフォン幅で文字・ロゴ・画像が重ならないことを確認する。
7. 他ゲームのページとリンクも維持されていることを確認する。
8. ポータル作成チャットの既存の公開・承認手順に従って公開する。

現行ビルダーが同じ構成なら、詳細ページは `games/high-low/` になります。掲載順・作品番号・ニュース追記はポータルの最新方針に合わせてください。ニュースの日付を捏造せず、実際の掲載日にします。PNGをそのまま使うJSONを同梱しているため、WebP素材は必須ではありません。

## 維持すべきゲーム仕様

| 難易度 | 数学の範囲 | 操作 |
|---|---|---|
| EASY | オペランドと結果が0〜100の整数の四則演算。割り算は割り切れる式のみ。同値問題なし | LEFT / RIGHT |
| NORMAL | EASYと同じ算術範囲。同値問題は約15% | LEFT / EQUAL / RIGHT |
| HARD | 分数・小数・平方根・特殊角の三角関数・指数・対数・絶対値・数列などの検証済みテンプレート | LEFT / EQUAL / RIGHT |

基本時間はPLAYING中の累積30秒で、実際の試合の所要時間は演出分だけ長くなります。正解100点、5連続から120点、10連続から150点、20連続から200点。誤答は−100点、下限0点、コンボリセットです。ランキングの期間境界は日本時間、週間は月曜0時始まり。同得点では正答率、平均回答時間の順で比較し、完全同点は同順位です。
