# HIGH×LOW Ver.0.1

独立した、ブラウザだけで動く30秒の数学比較ゲームです。

## すぐ遊ぶ

`artifacts/HIGH-LOW-v0.1.html` をダウンロードし、Chrome / Edge / Safari / Firefoxなどのブラウザで開いてください。単一HTML版はインターネット接続、Node.js、サーバーが不要です。スマートフォンではHTMLファイルのプレビュー機能ではJavaScriptが動作しない場合があるため、Webサーバーに配置した `dist/` のURLから遊ぶ方法を推奨します。

難易度を選んでPLAY。左右の数式の値を比較し、大きい方をタップします。同じならEQUAL。PCは←・→・↓キーを使えます。EASYはEQUALなし。30秒の実回答時間が終了すると結果が表示され、RETRYで再挑戦できます。

別アプリや別タブに移動すると中断し、記録は保存されません。保存が禁止された環境でもゲームは継続できます。file:// の保存はブラウザ依存です。継続的な記録には同じWeb URLをご利用ください。

## ローカルサーバー

```sh
cd /workspace/sites/high-low
npm start
```

そのPCの `http://localhost:8080` にアクセスします。ポートが使用中の場合は `python3 -m http.server 8081 --directory dist` などを使ってください。`dist/` は任意の静的ホスティングにそのまま配置できます。既存ポータルから独立したサブディレクトリでも動作します。

## 構成

- `dist/engine.js` 問題生成、厳密比較、時計、状態、採点、解答履歴。DOMやストレージへの依存なし。
- `dist/storage.js` バージョン付きローカル保存。破損・アクセス拒否に対応。
- `dist/app.js` UI、キー操作、背景移行の処理。
- `dist/style.css` 縦画面・セーフエリア・横画面対応。欧文フォントを埋め込み、外部通信不要。
- `tests/game.test.js` 数学・時計・採点・保存の自動テスト。
- `tests/browser.py` Chromiumでの画面・実時間試合・タップ・キー・リトライ検証（Playwrightが必要）。
- `scripts/package.py` 単一HTML・ソースZIPの生成（Python標準ライブラリのみ）。

```sh
npm test
python3 scripts/package.py
python3 tests/browser.py
```

ブラウザテストはソケット・ブラウザプロセスの起動を許可された環境で実施してください。現在の実行環境では起動が制限されており、ブラウザテストは未完了です。

## 拡張

`Generator` には任意の乱数関数、`Game` には時計と乱数を注入できます。`seeded()` で共通問題セットの再生を行えます。解答履歴には問題、選択、実回答時間、回答後の点数を保存します。オンライン対戦時はサーバー側でシード、受付時間、採点を管理する必要があります。

HARDの値は非負の `n × √rad / d` に限定します。BigIntで両辺の平方を比較するため浮動小数点近似を使いません。負の値や一般的な超越数を扱うテンプレートは、この比較器を拡張するまで追加しないでください。
